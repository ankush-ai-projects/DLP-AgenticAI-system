# DLP System - Frontend

Modern React frontend for Data Loss Prevention System with Futuristic Neon UI.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 📦 Tech Stack

- **React 18+** - UI Library
- **Vite** - Build Tool (Fast!)
- **React Router** - Navigation
- **Axios** - API Calls
- **Recharts** - Charts & Graphs
- **CSS3** - Neon Animations

## 🎨 Features

- ✅ Futuristic Neon Landing Page
- ✅ Complete Dashboard with Charts
- ✅ Real-time PII Detection
- ✅ File Upload Scanner
- ✅ Scan History
- ✅ JWT Authentication
- ✅ Responsive Design

## 🔧 Setup

1. Make sure backend is running on `http://localhost:8001`
2. Install dependencies: `npm install`
3. Start: `npm run dev`
4. Open: `http://localhost:3000`

## 📝 Environment

Backend API: `http://localhost:8001`
Frontend: `http://localhost:3000`

## 🎯 Pages

- `/` - Home (Landing Page)
- `/login` - Login
- `/register` - Register
- `/dashboard` - Main Dashboard
- `/scanner` - PII Scanner
- `/history` - Scan History
